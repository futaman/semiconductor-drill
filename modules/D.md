# モジュールD「どこで使われてる？」メモ

## 構成（6章）

通し線は、S1の「段差」と「後押し（光・熱・混ぜ物・電圧）」。D1の発見で「使い道の地図」（光で登らせる／熱で登らせる／電圧で開け閉めする／落として光らせる）を出し、D2〜D6でその地図を1つずつたどる。

| # | テーマ | ①問い | シミュレータ | 「ほぅ」→ 次の問い |
|---|---|---|---|---|
| D1 | 部屋の中の半導体 | 電卓・LED・体温計のうち、半導体が入っていないのは？（答え：どれにも入っている） | `room` 部屋の中を探す（TEL「半導体を探そう！」式）／`phone` スマホの基板で役割→チップを結び、写真1枚のバトンを見る | 仕事の違いは「段差を越えさせる後押しの使い方」の違い → 光で登らせると、なぜ写真が撮れるのか |
| D2 | 目と温度計 | カメラの目で何が起きている？ | `sensor` 画素に電子がたまって写真になる（光の量・時間・センサーの温度）／`thermo` 半導体と銅を温める | 写真は「電子の数の地図」。熱も後押しになる（カメラにはじゃま、温度計には信号）。サマリから外した「温めると通しやすくなる」をここで回収 → 数えた数字はどこへ |
| D3 | 頭脳・作業机・保管庫 | DRAMはどれくらいの頻度で書き直す？（1秒に十数回） | `memory` 同じ絵をDRAMとフラッシュに書き込み、書き直し・電源を切る | DRAMは漏れるコップで64ミリ秒ごとに書き直す。フラッシュは「崖」（S1の絶縁体）に電子を閉じ込める → 画面を光らせるのは |
| D4 | 光る半導体 | 白いLEDはどうやって白い？ | `ledcolor` 段差の高さ→光の色、蛍光体をかぶせると白 | 1つの段差からは1つの色 → 青＋黄の蛍光体。だから青色LEDが照明を変えた → 逆に光を当てたら |
| D5 | 逆再生：太陽電池 | LEDに光を当てると？（わずかに電気が生まれる） | `solarband` 太陽の光の粒と段差の高さ（素通り／余りは熱、取り分の上限のグラフ）／`angle` パネルの傾きと季節の太陽の高さ | シリコンの段差（約1.1）は太陽の光にちょうどいい高さ（グラフの山の頂上）→ 車を走らせる電気は |
| D6 | EVを動かす | 半分の強さを出すには？（全開・全閉のすばやいくり返し） | `power` 半開きで絞る vs すばやくオンオフ、材料 シリコン／SiC | 段差の高い材料（SiC、GaN）ほどむだが少ない。GaNは青色LEDと同じ材料 → E（作る国と会社） |

- アナロジー：バケツで雨を測る（D2）、穴のあいたコップ（D3）、動画の逆再生（D5）、ブレーキを握ったままこぐ自転車（D6）。すべて「崩れるところ」付き
- 役割を先に、部品名は後に：目＝イメージセンサー、頭脳＝プロセッサ、作業机＝DRAM、保管庫＝フラッシュメモリ、電気の配り役＝電源IC
- 伏線の呼び出し：D1 で S1「段差」、D4 で A4（図は D 側の `drop`）、D5 で D4
- ふりかえり章は作っていない（6章とも内容の章）。D1 の部屋の図が目次の役割をする

## エンジンへの要望

1. **canvas の高さを親の幅から決めたい**：D では、canvas を `clientWidth` に合わせて描き直す小さなヘルパー（`kit`）をモジュール内に書いた（文字を 11〜13px のまま保つため。固定サイズの canvas を縮めると、375px で文字が 6px ほどになる）。ほかのモジュールでも同じものが要るなら、エンジンの共通部品にするとよい
2. **mount の失敗がコンソールにしか出ない**：`mountSims` は例外を `console.error` に出すだけで、画面上は空の図になる。制作中に気づきにくいので、開発中だけでも図の枠に「読み込めませんでした」と出すと安全
3. **recall の図はサマリとそのモジュールの図しか使えない**：`figFn` が `COURSES[st.mod].figs` と `FIG` しか見ないので、D4 から A4 の図を呼べない。D は自前の `drop` を描いた。`recall` に `figMod: 'A'` のような指定があると、伏線の図を共有できる
4. **予想に答えないと発見が開かない章で、explore のシミュレータの結果を発見の本文が参照している**（D2 の「熱いセンサー」、D5 のグラフの山）。今のままで問題はないが、発見を開いたときに該当のシミュレータへ戻るリンクがあると親切

## SPEC への反映

- 6章 A の表のあとに「D『どこで使われてる？』」の節を足す：上の表（テーマ・問い・ほぅ）と、通し線が「段差と後押しの使い方」であること
- 4章「伏線：段差」の表に追加：
  - D1：使い道の地図（光で登らせる／熱で登らせる／電圧で開け閉めする／落として光らせる）
  - D2：熱も後押しになる → 温度計（サマリから外した「温めると通しやすくなる」の回収先）
  - D3：絶縁体の「崖」に電子を閉じ込める＝フラッシュメモリ
  - D5：シリコンの段差は太陽の光にちょうどいい高さ
  - D6：段差が高い材料（SiC・GaN）は、大きな電気をむだなく扱える
- 6章「B以降のアナロジー候補」の「温度で電気の通しやすさが変わる話 → D（温度センサー）」は、D2 で採用済み
- 9章：D は 6章構成でふりかえり章なし（A は a6 がふりかえり）
