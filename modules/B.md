## エンジンへの要望

1. **クラス名の衝突**：エンジンの CSS に `.b-up` `.b-low`（S1 の段差の図）がある。モジュールBのクラスは `.b-` で始めるルールなので、将来ぶつかる恐れがある。B.js ではこの2つを使っていないが、エンジン側を `.band-up` などに改名するか、ルールを `.bm-` などにするとよい。
2. **ハッシュの変更で再描画されない**：`#b1` → `#b2` のようにハッシュだけ変えても画面が変わらない（`hashchange` を見ていない）。アドレスバーで章を行き来したときや、ブラウザの戻るで困る。`window.addEventListener('hashchange', boot)` があるとよい。
3. **発見の見出し**：予想に答えたあと、発見の区切り見出しが `'③ 発見'` に固定で上書きされる（`st.labels.discover` が無視される）。Bでは labels を使っていないので実害はない。
4. **viewport の meta がない**：`index.html` に `<meta name="viewport" content="width=device-width, initial-scale=1">` がないので、ローカルで実機（スマホ）から開くと980px幅で表示される。Artifact として公開すると枠が補うなら問題なし。
5. **C〜E.js の 404**：ファイルがないモジュールは読み込みで 404 がコンソールに出る（エラーではないが、「コンソールにエラーがない」の確認でまぎらわしい）。

## 数字と出典（確認済み）

- ENIAC の累算器：1桁を10個のフリップフロップの輪（環状計数器）で表した（Wikipedia「ENIAC」、Drexel大学 Brian L. Stuart の ENIAC 解説）。
- 中嶋章・榛澤正夫：1934〜36年にスイッチング理論の論文（電気学会の顕彰資料、情報処理学会 コンピュータ博物館）。シャノン：1937年 MIT 修士論文、1938年発表。※中嶋が「先」かどうか・影響関係は資料により評価が分かれるので、本文では先後を言い切っていない。
- アポロ誘導コンピュータ Block II：約2,800個のIC、ほとんどが入力3つのNORを2つ収めたチップ（Wikipedia、スミソニアン航空宇宙博物館の収蔵品記録）。Block I の個数は資料で 4,100 と 4,700 に分かれるので使っていない。
- NAND型フラッシュ：東芝の舛岡富士雄ら、1987年 IEDM で発表（キオクシアの記事）。発明年は1986年とする資料もあるので、本文では年を出していない。
- 全加算器＝NAND 9個、CMOS の NAND＝4トランジスタ・AND＝6、SRAM＝6トランジスタ：標準的な回路の数。
- 38億回：A17 Pro の約3.78GHz（S2 の出典と同じ）。
