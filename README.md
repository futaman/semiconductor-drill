# 半導体ドリル

中学生レベルの知識の大人が、半導体を段階的に理解できるWebドリルです。
予想して、触って確かめて、自分の言葉で説明できるところまで。

- **公開ページ**：https://futaman.github.io/semiconductor-drill/
- サマリ（5章）＋モジュールA〜E（各6章）、全34章
- 各章に、触って確かめる簡易シミュレータ（全51個）

| モジュール | 内容 |
|---|---|
| サマリ | 半導体ってなに？ |
| A しくみ | 電子、シリコンの結晶、n型とp型、ダイオードとLED、トランジスタ |
| B 計算のしくみ | 0と1、AND・OR・NOT、NANDだけで組む、足し算、記憶 |
| C つくりかた | 純度、ウェーハ、版で刷る、体をつくる、配線、検査と歩留まり |
| D どこで使われてる？ | センサー、メモリ、LED、太陽電池、パワー半導体 |
| E 社会と産業 | 真空管からICへ、ムーアの法則、工場の値段、分業、経済安全保障 |

## ファイル

- `index.html`：共通エンジンとサマリ
- `modules/A.js`〜`E.js`：各モジュール（`modules/X.md` は制作メモ）
- [SPEC.md](SPEC.md)：仕様書／[MODULES.md](MODULES.md)：モジュールの作り方／[KNOWLEDGE.md](KNOWLEDGE.md)：見せ方の調査

## ローカルで見る

```bash
python .claude/serve.py
```

http://localhost:8765/ を開く。
